# 📌 Project Overview

This project automates the complete **Ixigo Train Booking Workflow** using:

- ✅ Selenium WebDriver
- ✅ Pytest Framework
- ✅ Behave BDD Framework
- ✅ Page Object Model (POM)
- ✅ Allure Reporting
- ✅ HTML Reporting
- ✅ Excel Driven Testing

The framework validates the complete booking journey from:

```text
Login → Train Search → AVL Seat Selection → Passenger Selection → Payment Page
```
